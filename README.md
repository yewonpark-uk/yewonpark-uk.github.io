# Yewon Park — Product Manager

A single-page editorial portfolio in British English. Plain HTML and CSS, with no build step, dependencies, tracking or external fonts.

## Preview

Run `python3 -m http.server 4173 --bind 127.0.0.1` from this directory, then visit http://127.0.0.1:4173.

## GitHub Pages

The site is published from the `main` branch and `/ (root)` at `https://yewonpark-uk.github.io/`. The `.nojekyll` file keeps this a plain static site.

## Content notes

- The homepage presents Guam and SOCAR Malaysia as separate launches, followed by KakaoBus and FASTFIVE. Globee is an independent product, with the live directory and the nearby search experiment labelled separately.
- South Korea is the employment base for the Malaysia and Guam projects. SOCAR and FASTFIVE dates describe the roles; the Guam and KakaoBus dates describe the projects. The Guam project is shown as September–December 2021, as agreed for the CV.
- Ahn Graphics is a **Project Manager** role, not Product Manager. Earlier experience and existing publishing/brand ventures are retained without inventing new dates or results.

- KakaoBus uses official product screenshots from its App Store listing, stored locally with descriptive alt text. The other case visuals describe the relevant workflows and launch scope.
- The contact section links to Yewon's professional email and LinkedIn profile. The public project summaries use service scope and released capabilities to describe the work.
- No metrics, employers' dates, case-study results or product interfaces have been invented.
- No PDF or custom-domain configuration is included. Add `yewonpark.uk` only when the domain is ready.
