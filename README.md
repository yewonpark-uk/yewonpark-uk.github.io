# Yewon Park — Product Manager

A single-page editorial portfolio in British English. Plain HTML and CSS, with no build step, dependencies, tracking or external fonts.

## Preview

Run `python3 -m http.server 4173 --bind 127.0.0.1` from this directory, then visit http://127.0.0.1:4173.

## GitHub Pages

The site is published from the `main` branch and `/ (root)` at `https://yewonpark-uk.github.io/`. The `.nojekyll` file keeps this a plain static site.
